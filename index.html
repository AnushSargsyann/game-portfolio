Crystal Quest

  • Engine Unity
  • Language C#
  • Genre Adventure / Platformer
  • Role Level Design & Programming

Crystal Quest was my very first project when I entered the game development industry. I created this game in just one week, taking responsibility for both level design and programming.

The player's objective is to collect all the crystals while avoiding poisonous mushrooms scattered throughout the level. This project gave me my first hands-on experience in level design, gameplay programming, and bringing a complete game concept to life using Unity and C#.

06

Horror Mansion

  • Engine Unity
  • Language C#
  • Genre Horror / stealth

Horror Mansion is a suspense-driven horror game built around sound-based enemy distraction, strategic object interaction, and survival. Players must explore their surroundings, collect essential items, and use throwable objects to create sounds that distract enemies, manipulate their movement, and avoid detection.

One of the key mechanics is a dynamic heartbeat system: as an enemy approaches, the player's heartbeat becomes faster and more intense, with an audio effect and a visual heartbeat indicator on the UI — so players can sense danger before an enemy appears. A magical guiding light, a glowing orb, travels between locations where collectibles are hidden, helping players navigate while keeping the mysterious atmosphere.

The project combines immersive level design, interactive mechanics, sound design, visual guidance and psychological tension — a horror experience where every sound, movement and decision matters.

07

Medieval Kingdom Siege

  • Engine Unity
  • Language C#
  • Genre 2D Strategy / Defense
  • Mode Single-player

Medieval Kingdom Siege is a single-player 2D side-scrolling strategy and defense game inspired by Kingdom Two Crowns. Players must build walls, strengthen their kingdom, and defend their castle against incoming enemy attacks.

Beyond survival, the main objective is to destroy two enemy portals from which hostile creatures continuously spawn. The project focuses on resource management, strategic base building, enemy defense, and objective-driven gameplay.
